# 音乐前台流程主机测试

本目录验证音乐应用的前台流程（`APP/apps/music/foreground/`，STOR-6、STOR-15、STOR-16、ARC-24、ARC-26、ARC-27，#218）和它的证据出口。测试链接真实的 `music_foreground.c`、`music_row_cache.c`、`music_cells.c`、`ui_cell.c`（含持锁统计）、`music_display_stats.c`、`music_hook_pageturn.c`、共用 FreeRTOS 桩（互斥锁、tick、通知）和脚本化的周期计数器与 Service Log 替身；曲库读者、曲目文本读取、读标签诊断、卷边沿时刻、块池就绪数和前台叫醒函数在测试里用假实现，只实现既有的公开函数。前台流程对外的唯一入口是 `music_foreground_step()` 与两个需求格、两个结果格，测试只经它们观察。

15 个 CTest，每个用例一个进程：

- `music_row_cache`（9 个用例）：启动后什么都没缓存；放入后取回同一行；代次不同、位置不同都是未命中；相差 64 的两个位置共用一行、后放的赢；连续 64 个位置都留在缓存里；代次 0 不缓存也不命中；启动清零键表；行数是 64。
- `music_foreground`（37 个用例，默认构建）：没有需求什么都不做；写需求叫醒前台、发布结果不叫醒；**凑齐才发布**（一窗的行没读完 GUI 看不到半窗）、末窗只含存在的行、起点越过列表尾发布 0 行；**新窗口需求覆盖旧的**（已读的行不重读）；**缓存命中不读文件**，全部命中的窗口不做文件调用就重发；曲名与窗口共用行缓存；每一步先看曲名再看窗口；曲名结果回带需求序号、只答最新一次；曲名代次 0 表示当前、代次不符答 0；越界的曲名对“当前”静默、对显式代次记 `Name fail` WARN；不需要的曲名需求不读文件；读窗口期间曲库代次变了发布代次 0 的空窗，随后不需要新需求就按最新需求重发，空窗与新窗口是两次独立发布；拔卡发一次空窗、卡回来再发窗口；曲库还没好时发空窗，曲库发布后发真窗口；空窗记下卷边沿时刻供“拔卡后 Queue 清空”延迟用；**失败不缓存**：打开失败显示回退名但不缓存、读取错误不缓存、卷不可用的行留空且不缓存、稳定结果缓存、防御分支的单行失败不中断整窗；**`SERVICE_BUSY` 约 10 ms 后重试**，期间不显示回退名，重试后的结果会缓存，曲名同样处理，重试次数有上界；曲名在曲库发布之前被问过则发布后重答；读标签时卷已消失答 0 且不记 WARN；曲名的防御失败记 WARN；曲名读失败显示回退名且不缓存；因锁没读到需求格时尽快重试（`ui_cell_changed()`）；空闲时等通知、忙时要求再调；`boot_init` 忘掉缓存与待办。
- `music_display_stats_*`（5 个用例加 1 个发布构建用例）：没有样本不出行；每个节拍一行，分别报本节拍与开机以来的最大值；拔卡清空延迟从卷边沿算起，来源用掉一次即清除；tick 回绕不让延迟虚高；极端值被钳住、整行不超长。发布构建（`-DNDEBUG`）另编一份，确认汇总是空操作（`music_display_stats_release_is_empty`）。
- `music_hook_pageturn_*`（5 个用例加 1 个默认关闭用例）：默认构建什么都不做；钩子打开时投启动行；没注入就不测；补满耗时从注入量到块池回到水位；补不满按超时记一行 WARN；新注入取代没量完的测量。
- `music_foreground_locator_miss_hook`：同一份测试源另带 `AUDIO_READER_HOOK_LOCATOR_MISS=1` 编一份，37 个用例再跑一遍；其中定位符用例在钩子打开时断言前台交给文件读取的定位符被清零（曲名与窗口行都是）、别的字段不变，在默认构建里断言定位符原样交下去。

保真边界：主机测试是单线程的，PASS 证明状态机各分支的行为正确，不证明真实交错：不证明前台与音频读取争 SD 锁时的等待时间和让路、与 GUI 同级时的时间片、`ui_cell` 的真实持锁时长和 GUI 拿不到锁的频率、一步的真实耗时（文件调用和 CPU 用假实现与脚本化计数器代替）、真实的标签读取代价（曲库、标签读取是假的）、前台任务的栈。这些进板级验收（清单 3 第 5 次，R5.1 至 R5.8）。GUI 一侧的客户见 [Tests/music_gui](../music_gui/README.md)，前台循环见 [Tests/foreground_task](../foreground_task/README.md)。

从仓库根目录运行：

```powershell
./scripts/test-host.ps1 -Module music_foreground
```
