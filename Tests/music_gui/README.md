# 音乐 GUI 主机测试

本目录验证音乐应用 GUI 分区（`APP/apps/music/gui/`）里五块与 LVGL 无关的逻辑；原来在 `Tests/gui_task`，#216 随目录搬动，用例只改了路径：

- `gui_music_queue_window.h`（#218 按新的格子协议重写）：窗口客户写需求与读结果——首帧立即写窗口需求；写不进（拿不到锁）下一帧重试；读到新窗口 APPLY 且不再重写需求；**窗口不比需求序号**（对应旧需求的窗口晚到也照常套用，#200）；套用失败从 GUI 的窗口副本重试、不重新要窗；更新的窗口取代失败的那个；代次 0 的空窗对正显示的 Queue 清空一次（`CLEAR`），没显示过窗口时什么也不清；清空之后需求回到起点 0；滚动换窗 Index（回滑留 3 行、近起点夹到 0、窗口不足一窗不前进、跳滚一次到位）；想要的起点又变就写新需求而不等上一份结果；**起点又回到已显示的窗口就写回去撤销上一个还没答的需求**；回滑范围内不重写；APPLY 记下已显示窗口的代次；
- `gui_music_transport.h`：播放快照到显示决定的纯 C 归约（冻结与序号、Queue 高亮与队列满撤回、进度与时间、停止短语、跳过/停止计数、唱盘按 `TrackStartCount`、身份变化与进入停止归零、位置变小不归零）和命令编号，以及接线后 `gui_music.c` 依赖的快照序列回归（开机开播时代次确认、回显落后时换窗的高亮、队列满撤回后追上）；用假的 `playback_command_send()` 替身，只经合同头 `playback_contract.h`；
- `gui_music_title.h`（#218 按新的格子协议重写，**曲名要比需求序号**）：曲名客户——无当前曲显示 `--` 不写需求、有当前曲留空并按其身份写带序号的需求、等结果期间不重复写、序号等于最新需求的有效结果采信为名字、结果代次 0 显示 `--` 且不重写、身份变化即清空并写序号更大的需求、**答给被覆盖需求的结果丢弃，答给最新需求的采信**、连按 NEXT 只采信最后一首、坏文件跳过按候选写需求、在途期间失去当前曲显示 `--` 且不再写、需求拿不到锁写不进时下一帧同一序号重试（失败不占序号）、身份冻结时名字保持不写；冷启动代次 0 → G 时已显示名字的结果代次等于 G 则保留、不等则重写，代次 0 的需求在途时结果代次等于 G 采信、否则丢弃并按 G 重写；**前台在曲库发布后用同一序号再答一次时，后到的名字替换先到的代次 0 的 `--`**；归约测试另断言决定给出的曲目身份未追上时冻结；每次 Apply 同时断言曲名与歌手（`gui_music_title_text()`）：应答到达时两列同次出现、歌手为空串或 NULL 时交出 `Unknown Artist`、切歌先同次清空成 ("", "")、连按只交出最后一首、坏文件跳过交出候选的两列（含中文与多歌手）、过期应答不交出任何文本、冷启动 0 → G 保留两列不再清空、无当前曲 / 拔卡 / 空库 / 取不到名字为 ("--", "")；
- `gui_music_queue_rows.h`：Queue 窗口客户把窗口副本（`MusicCells_WindowTypeDef`，GUI 一侧的拷贝）的两列文本按行交出——曲名与歌手平行（第 i 项同属窗口第 i 行）、歌手为空串的行交出 `Unknown Artist`（GUI-25，不是空串、NULL 或 `--`），副本里的歌手仍是空串、`Length` 超容量时截到容量、空窗 0 行；只按格子的类型头构造窗口，不链接前台任务实现；`QueueApply` 把歌手画进行由模拟器场景 `queue_tags`、`queue_track_text` 覆盖；
- 跳转归约（`test_gui_music_seek.c`，同样只经 `gui_music_transport.h` 与假 `playback_command_send()`）：拖动中预览“目标/按下时的总时长”；松手发 SEEK（按下时的身份、`TargetMs` = 比例 × 按下时的总时长，两端 0 与满量程）；按下绑定总时长（拖动中总时长变化不影响）；发送后位置保持目标直到回显序号追上、连续松手保持最后一次；队列满不保持、回到快照；之后再发 NEXT 时回显追上 SEEK 即不再保持；拖动中换曲或进入停止给出一次 `seek_cancel`、按新快照显示、之后松手不发；触摸丢失取消；总时长未知与停止态（含 AUDIO_FAULT）不响应按压、`seek_enabled` 为假；跳转（含跳到 0、暂停中）不让唱盘归零；

不链接 LVGL、FreeRTOS、HAL、播放任务、`ui_cell` 实现（客户都是纯函数，`ui_cell` 的读写在 `gui_music.c` 里，由模拟器场景覆盖）；`gui_music.c` 的编排与 Service 吞掉按压（`SeekEnable`/`SeekCancel`）由 GUI 模拟器场景覆盖（`music_seek*`）。Host PASS 不证明真机跟手滚动、拖动、换标或插拔时序，也不证明 GUI 与前台任务通过格子交接的真实并发（单线程，`ui_cell` 在这里不参与）：GUI 写需求拿不到锁、前台答复的时延与刷新节拍的组合进第 5 次上板（R5.1、R5.3）。

从仓库根目录运行：

```powershell
./scripts/test-host.ps1 -Module music_gui
```
