## Library、阅读与设置

| 目标 | 已确认意图 |
| --- | --- |
| Library | SD Music/ 来源；两列专辑封面网格，首版可用假标题/歌手/封面，不显示空 Flash 音乐分区。 |
| Album Detail | 属于 Music，不新增 Main 页；三标签变返回+标题，约 160 ms ease-out 转场（标签移出、标题滑入、列表淡入上移），返回反向。保留全局横滑、列表纵滚。 |
| Mini Player | 仅专辑详情底部：小封面、曲名、播放键，点击回 Now Playing，不复制完整进度条。 |
| Bookshelf | BooksPage 两列书卡，含书名/封面/进度，点击进入 Reader。 |
| Reader | 沉浸阅读，禁用 Main 横滑；左右翻页采用 120–160 ms 平移与窄阴影；中央点击显示覆盖式上下工具栏，不能挤正文/重分页，翻页或无操作约 3 s 后隐藏。上栏返回/书签/列表，下栏字号/假亮度/进度。 |
| Settings | 2×2 卡片：Playback（音量/顺序、无 EQ）、Display（亮度/自动锁屏/Wallpaper）、Typography（系统字号/未来字体）、System（时间/设备/电量/存储/版本）；子页返回+标题。阅读字号归 Reader，不混入系统字号。 |
| Wallpaper | Display 下静态预览卡，选中以 Accent 细边/勾表示；初版只验证选择与跳转，不承诺持久化/真切换。Solid 不显示壁纸；候选仍待确认。 |
| Lock 扩展 | 时间日期之外保留 Mini Player；安全认证、唤醒/背光另行决策。 |
| 唱盘扩展 | playing 旋转、paused 保持角度；有效当前曲才合成封面，CLEAR/空表仅唱盘。旋转属于 vinyl，不放 transport。 |

专辑详情曾确认的 240×320 布局保留作实施起点：状态栏 (0,0,240,22)、标题栏 (0,22,240,42)、摘要 (12,68,216,52)、封面 (12,70,48,48)、文字起点 (72,72)、列表 (12,128,216,124)、Mini Player (8,260,224,52)。曲目行 40 px，只含序号/曲名/时长，不加收藏按钮。

真实亮度需 Platform LCD/PWM 能力，不用半透明遮罩冒充背光；Boot 只预留时序位置。

## 可换壁纸与缓存

目标为运行时按壁纸生成并缓存 Clear/Blur，不能为每张候选编译模糊副本或用深色罩冒充模糊。当前仅启动一次生成，持久缓存/背光渐亮尚未实现；生效资源仍来自机内 Pack，设备安装边界见[资源规则](resources.md)。

后续缓存键包含内容校验值、尺寸、格式、算法版本、半径；命中则载入，失配则在低背光且 Boot 尚未展示有效内容时生成，并异步补写缓存。正式格式暂定预合成不透明 240×320 RGB565，Clear/Blur 合计约 300 KiB；必要乒乓第三帧约 450 KiB。不得将当前 Alpha 验证帧误记为已完成的 RGB565 缓存。正式长期接口、容量和 Cache 一致性实施前再审校。

## Settings 局部玻璃

所有权模型经早期状态原型验证，功能尚未接线：清晰壁纸复制成页面长期合成帧，仅把各圆角卡片区域替换为同位置 Blur，再叠透明染色/边框/正文。共用短期全屏工作区，不为每张卡片分配长期 Canvas/整屏副本。壁纸、位置、尺寸、圆角变更才重建；静止或文字更新不重新模糊。

共享工作区加 Settings 合成帧的 Alpha 峰值约 450 KiB，RGB565 约 300 KiB。半径、圆角裁剪、耗时与 SPI 刷新成本仍需真机测量；统一绑定/缓存失效/长期接口要先审校。原型历史由 Git 保存，不恢复 scratch 文档。
